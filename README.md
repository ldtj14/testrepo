## Unity 2021 sample scripts
The `unity-sample/Assets/Scripts` folder contains starter C# scripts you can drop into a Unity 2021 project:
- `PlayerController.cs` for movement, rotation, and jumping with the new Input System callbacks.
- `InputReader.cs` to translate Input Actions into events for gameplay scripts.
- `GameManager.cs` to track score and health with simple UnityEvents for UI binding.
- `EnemyController.cs` for a lightweight patrol enemy that damages the player on contact.
- `WaveRunner_AllInOne.cs` placeholder to drop in the Wave Runner single-file pack when ready.
